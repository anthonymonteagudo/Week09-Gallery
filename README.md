**Public download. No GitHub sign-in required.** This is the actual Week 9 gallery project, including its materials, textures, meshes, Blueprints and editor navigation.

1. Download **Week09-Gallery-Project.zip** using the link above or the latest Release. GitHub's green **Code → Download ZIP** contains only the small repository files; use the release asset for the full Unreal project.
2. Extract the entire archive to a short local path, such as `C:/Teaching/Week09`.
3. Open **`Week09MaterialLab/Week09MaterialLab.uproject`** in **Unreal Engine 5.7.4**. Allow initial shader compilation to finish.
4. The startup map is **`/Game/Week09/Maps/W09_MaterialGallery`**. Use the **Week 9** editor menu to navigate the gallery and master-material area.

The download includes the complete saved Content tree. No additional Fab download or local automation plugin installation is required. Keep all Content folders intact.

The gallery contains 23 comparison stations: parameter scope, world projection, vertex/height blending, directional snow, decals and puddles, clear coat/layers, parallax, foliage WPO, flow direction/masks, burn and disintegration, shield, slime, interiors/glass, Star Nest HLSL, post-process examples and optional diagnostics. The master-material reference occupies its own area.

In Play: **I** ignites the LIVE burn/disintegration specimens, **R** resets, **C** removes the hot edge while progress continues. Niagara edge particles are not implemented. Shield impact and slime are material demonstrations; the optional Landscape material is not a finished Landscape station.
